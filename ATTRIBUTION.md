## NASA NAIF / JPL / Caltech SPICE

This project contains Rust adaptations of numerical algorithms and operation order from the official CSPICE N0067 source. It is third-party software, not the official toolkit, and it does not link CSPICE at runtime. It must not be described as a clean-room implementation or as NASA-certified.

Original work: California Institute of Technology under contract with NASA. Official distribution: https://naif.jpl.nasa.gov/pub/naif/toolkit/C/PC_Windows_VisualC_64bit/packages/cspice.zip

Archive SHA-256: 98d60b814b412fa55294aeaaeb7dab46d849cc87a8b709ffe835d08de17625dc.

Routine-level hashes and algorithm notes are retained in docs/reference/CSPICE_N0067.json, CK_PCK_SOURCE_HASHES.json, SGP4_SOURCE_HASHES.json, DYNAMIC_FRAME_SOURCE_HASHES.json and DSK_SOURCE_HASHES.json. These identify interpolation, propagation, orientation, frame, shape and GF algorithms actually used. The generated Wahr coefficient table and SGP4 source-adaptation generator retain their provenance.

## Kernel data and independent fixtures

Official downloaded ephemeris, orientation, clock, instrument and shape data remain in ignored target/ caches. Their producers, file hashes and load order are recorded in reference and audit manifests. The full toolkit archive is not redistributed in the crate.

Synthetic kernels in tests/golden are generated by the included tools for independent conformance testing; converted byte-order fixtures use distinct filenames. They are test data, not flight ephemerides or official NASA mission products.

## STKCraft-time

STKCraft-time 0.1.18 supplies the independent time/LSK/SCLK contract and is distributed under its own MIT license and attribution notices. See https://github.com/spacelibres/STKCraft-time/blob/v0.1.18/ATTRIBUTION.md. This repository does not claim to relicense upstream data or inherited notices.

## Reference software

SpiceyPy 8.3.0 is used only to call the independent CSPICE N0067 reference runtime during fixture generation and validation. It is not a production dependency.
