# Support

Start with the [API guide](docs/API.md), [MCP guide](docs/MCP.md), [numerical contract](docs/NUMERICS.md), [coverage status](docs/STRICT_PARITY_STATUS.md) and [remaining gaps](docs/STRICT_REMAINING_GAPS.md).

Report ordinary bugs or questions at https://github.com/spacelibres/STKCraft-Geocalc/issues. Include the crate version, Rust/platform versions, complete input, kernel hashes/load order, expected reference and actual output. Include every differing component and semantic flag. Do not attach restricted mission data.

Use [SECURITY.md](SECURITY.md) for vulnerabilities. STKCraft-time issues belong to its independent repository; include an unchanged minimal integration reproduction.
