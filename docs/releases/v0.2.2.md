# STKCraft GeoCalc 0.2.2

This release includes the STKCraft GeoCalc web workspace, visual examples,
time integration, timeline, NASA display comparisons and the bounded native
reference work described in the [0.2.1 candidate notes](v0.2.1.md).

It preserves finder reference capture bytes across Git checkouts and stops
strict verification as soon as a prerequisite fails. The 0.2.1 candidate was
not published after its GitHub CI detected changed reference-file hashes.
The screenshot gallery records the 0.2.1 development workspace.

The comparisons cover the documented cases; complete WebGeocalc parity and
unpublished NASA internal binary values remain unverified. See the
[remaining gaps](../STRICT_REMAINING_GAPS.md).
