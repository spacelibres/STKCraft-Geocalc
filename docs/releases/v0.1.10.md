# STKCraft-Geocalc 0.1.10

This release includes the 0.1.9 text-kernel/Time integration checkpoint,
which remained untagged after its remote bootstrap hit a removed NAIF URL.
The original, hash-identical Earth PCK is now retained as a reference snapshot;
no numerical inputs or expectations change. See
[snapshot provenance](../reference/PINNED_KERNEL_SNAPSHOTS.md) and
[the preceding changes](https://github.com/spacelibres/STKCraft-Geocalc/blob/v0.1.10/docs/releases/v0.1.9.md).

Explicit surface models now support native LATSRF coordinate construction,
typed ray intersections that preserve misses and ordering, and DSK-versus-point
GFOCLT searches in either depth order. Existing public signatures remain valid.

SINCPT's reported light time is derived from the returned surface vector;
missing selected DSK data returns the native DSKDATANOTFOUND symbol.
Independent C captures precede the changes and preserve every original value.
The new regressions cover 2,352 coordinate calls, 1,296 intersections through
both direct and typed paths, 864 DSK occultation queries and the existing
162 ellipsoid/point windows. See [the precise scope](../reference/DSK_MODEL_SCOPE.md).

This is an additive Rust API and numerical repair. Surface-name lookup,
exhaustive option/error products and new CLI/MCP model exposure remain open.
WebGeocalc point-location endpoints are not DSK surface specifications.
Time remains pinned to the independently published 0.1.29 release.

Full strict Debug/Release, all-feature/MCP, MSRV, rustdoc and package checks
are required before publication. Complete WebGeocalc parity remains false.
