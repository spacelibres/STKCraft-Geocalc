# STKCraft-Geocalc 0.1.6

This is the first repository publication of the repaired numerical core,
organized source tree, optional MCP server and Agent Skills. It is a
reproducible implementation checkpoint; complete WebGeocalc option-level
certification remains open.

## Changes

- All 16 N0067 SPK types and all six CK types, with native record, priority,
  interpolation and query-history regressions.
- Binary PCK 2/3/20, dynamic and switch reference frames, and explicit
  SPK/CK/SCLK context.
- Type-2 unprioritized DSK direct surface calculations, preserving native
  metadata, surface selection and error behavior.
- Distinct position-only and full-state paths for dynamic frame precision.
- MCP tools and Agent Skills using the existing Rust calculation engines.
- English documentation, source attribution, reproducible reference setup,
  version/changelog checks and release automation.
- Published dependency pin: STKCraft-time 0.1.18.

## Installation

```sh
cargo add stkcraft-geocalc@0.1.6
cargo install stkcraft-geocalc --version 0.1.6 --features mcp --bins
```

See [MCP configuration](../MCP.md), [API usage](../API.md) and
[source organization](../ARCHITECTURE.md). Release archives contain the
calculation bridges, MCP executable, notices and Agent Skills; verify the
attached SHA256SUMS.txt.

## Evidence and limits

The independent oracle is official CSPICE N0067. All 24 non-time families
have representative NASA output checks; native internal equality and NASA
serialization equality remain separate assertions. See
[current coverage](../STRICT_PARITY_STATUS.md),
[validation](../VALIDATION.md) and [remaining gaps](../STRICT_REMAINING_GAPS.md).

Linux/macOS builds are distribution checks, not additional native bit-parity
certification. Time conversion remains owned by STKCraft-time. Do not use
this release note as a claim that untested inputs or unfinished facades
match NASA.
