# STKCraft-Geocalc 0.1.13

Illumination and sub-solar calls now preserve the tested CSPICE short errors for
unsupported transmission corrections, absent DSK files, missing target DSK data
and points off a DSK surface. The observer/target validation order matches the
recorded native cases, and the target may also be the illumination source.
[Native captures and limitations](https://github.com/spacelibres/STKCraft-Geocalc/blob/v0.1.13/docs/review-2026-11-12/dsk-illumination-errors/README.md)
record the exact inputs and reference-library hashes.

The CLI rejects unknown sub-point kinds, endpoint and frame types, frame loci
and non-boolean orientation flags instead of selecting a different calculation.
Fixed points reject nonzero velocity; constant-velocity points use their stated
velocity and epoch. MCP forwards these validation failures and remains usable
for later requests.

Independent CSPICE captures exercise 288 CLI and MCP fixed/constant-velocity
location cases across selected frames, loci and corrections, comparing 2,016
state and light-time values by IEEE-754 bits. Another 54 derived fields and
all four fields of each of 42 original ellipsoid sub-point rows are checked
bitwise. The [location evidence](https://github.com/spacelibres/STKCraft-Geocalc/blob/v0.1.13/docs/review-2026-11-12/location-cli-native/README.md)
and [sub-point evidence](https://github.com/spacelibres/STKCraft-Geocalc/blob/v0.1.13/docs/review-2026-11-12/subpoint-bit-regression.md)
define their input and runtime limits. The full strict gate and release CI are
required before publication. Complete WebGeocalc parity remains false.
