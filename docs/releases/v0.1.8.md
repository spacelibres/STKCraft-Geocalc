# STKCraft-Geocalc 0.1.8

Windows reference builds use static UCRT math to remove the system-runtime
dependency reproduced by the pinned native CSPICE DLL on Windows Server 2022.
All original algorithms and numerical expectations are preserved.

## Numerical verification

- The new independent C fixture has 13,909 rows and 14,914 raw binary64 output
  cells across thirteen operations, including signed zero and subnormals.
- Its C oracle also rechecks the unchanged 204 VSEP and 288 PROP2B rows.
- Full Debug/Release and MCP acceptance remains mandatory, with no failed,
  ignored, skipped or missing required tests accepted.
- The log validator handles diagnostics interleaved between test names and
  completion statuses, while rejecting missing, ambiguous or failed statuses
  and similarly suffixed test names. Original logs remain unchanged.
- Native runtime captures, compiler/library/source hashes and the explicit
  [Windows profile](../NUMERICS.md#windows-runtime-profile) are documented.

## Distribution and documentation

Windows archives contain the exact executables exercised by the passing main
CI Release tests, verified by SHA256 and PE imports. Publication validates the
same commit's complete CI jobs, raw logs and source inventory. Linux/macOS
archives remain portable builds, without inheriting Windows bit-parity claims.

The crate includes the public English guides and reference scope documents.
Both [Agent Skills](../../.agents/skills) and the optional
[MCP server](../MCP.md) are distributed. Registry installation and downstream
library projects must explicitly configure the Windows static CRT; dependency
configuration is not inherited. Public Rust APIs are unchanged, and Time stays
pinned to the published STKCraft-time 0.1.18.

Complete WebGeocalc conformance remains false. Read the
[remaining gaps](../STRICT_REMAINING_GAPS.md),
[current evidence](../STRICT_PARITY_STATUS.md) and
[runtime investigation](../reference/RUNTIME_MATH_INVESTIGATION.md).
