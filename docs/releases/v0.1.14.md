# STKCraft-Geocalc 0.1.14

Named and numeric DSK surface lists can be resolved from text-kernel pools,
and a shared method parser supplies method-based LATSRF and J2000 SINCPT
entry points. The interface preserves the tested native validation order,
surface selection, misses and short errors. It does not yet expose DSK method
selection through CLI or MCP.

The SINCPT path accepts target-centered inertial frames and reports the native
missing or nonpositive radius errors. LATSRF and SINCPT distinguish no loaded
DSK files from loaded DSK files without matching data. Independent N0067
captures, inputs, hashes and tested limits are recorded in the
[surface-name evidence](https://github.com/spacelibres/STKCraft-Geocalc/blob/v0.1.14/docs/review-2026-11-12/surface-names/README.md).

This release is a conformance checkpoint. Complete WebGeocalc parity remains
unverified; see [remaining gaps](https://github.com/spacelibres/STKCraft-Geocalc/blob/v0.1.14/docs/STRICT_REMAINING_GAPS.md).
