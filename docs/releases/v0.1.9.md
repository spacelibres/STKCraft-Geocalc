# STKCraft-Geocalc 0.1.9

Text kernels preserve native assignment order, general append, case-sensitive
names and character types. Fixed/dynamic frame queries preserve native
metadata validation order and identity shortcuts. Repeated PCK loads no longer
reuse deleted or character-replaced constants, including after partial failure.

Independent N0067 C captures precede these repairs. New regressions check all
480 transformations in a 120-case frame matrix, typed pool operations, appended
frame/FOV/constants and PCK repeated-load behavior. See
[the exact scope and migration behavior](../reference/KERNEL_POOL_SCOPE.md).
Existing public Rust signatures are retained. Validation timing and partial
load state now follow the exercised native behavior.

Generated Python bytecode is omitted from source inventories; original native
binary outputs and diagnostics remain byte-for-byte evidence. Full strict
Debug/Release, MCP, MSRV, rustdoc and package checks are required before
publication. This file does not claim they have already passed.

Time remains an independent registry dependency pinned to 0.1.28. Native
kernel-date values are resolved directly without decimal reparsing; see
[Time integration](../reference/TIME_KERNEL_DATES.md). Wider date grammar and
short-error symbols remain outside the verified scope.
Complete WebGeocalc parity remains false; DSK facades, exhaustive option/error
products and other [remaining gaps](../STRICT_REMAINING_GAPS.md) stay open.
