# STKCraft-Geocalc 0.1.15

This release raises the minimum compatible STKCraft-time version to 0.1.33
and records that version in the release lockfile. The Time release adds
native-style type-1 partitioned SCLK strings, discrete ET boundary handling,
and selected native metadata and formatting behavior. GeoCalc continues to
use its existing APIs and explicit kernel inputs.

The release gate records the exact registry dependency source and its
checksum. Passing it establishes only the exercised numerical corpus and
platform, not complete WebGeocalc parity. See the remaining scope in
[STRICT_REMAINING_GAPS.md](../STRICT_REMAINING_GAPS.md) and Time's 0.1.33
release notes for its specific SCLK corpus and limitations.
