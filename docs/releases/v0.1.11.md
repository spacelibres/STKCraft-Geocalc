# STKCraft-Geocalc 0.1.11

Historical SPK type-10 packet epochs now initialize through Time 0.1.30's
explicit native ET-to-JDUTC API. This removes the post-1972 civil-coverage
blocker and the integer Epoch/calendar detour while retaining existing
public Rust signatures and distinct state/position paths.

An independent native C regression precedes the repair. All 33,696
query groups and 370,656 unrounded state, position and light-time cells
match; the existing 3,045 geometric-state and 270 corrected state/position
references remain unchanged. See [exact scope and evidence](../reference/SPK10_TIME_SCOPE.md).

The LSK must select the raw IERS-only/TableDriven model for native SPK10;
SOFA/frozen policies return explicit errors. No scientific historical UTC
model or replacement kernel is inferred. Time stays independently owned
and pinned to its actual published registry package.

Strict Debug/Release, all-feature/MCP, MSRV, rustdoc and package checks
are required before publication. Other option/error products remain open;
complete WebGeocalc parity is false.
