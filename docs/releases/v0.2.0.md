# STKCraft-Geocalc 0.2.0

This release upgrades the compatible `stkcraft-time` dependency range to
0.2.0 and records the selected version in the release lockfile. It allows
later compatible 0.2.x versions, each of which requires separate numerical
qualification.

## Migration

This is a breaking 0.x minor release: GeoCalc public methods that accept
Time types require the 0.2 series. Downstream projects using Time 0.1 must
update their dependency and rebuild. The geometric calculation interfaces
otherwise retain their existing behavior.

The exact reference gate applies only to its recorded source, kernels,
platform and test corpus. Passing it does not establish complete WebGeocalc
parity; see [STRICT_REMAINING_GAPS.md](../STRICT_REMAINING_GAPS.md).
