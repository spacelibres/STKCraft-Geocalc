# STKCraft GeoCalc 0.2.1

This release adds a local GeoCalc workspace with the STKCraft albatross
identity, guided geometry and event examples, an interactive solar-system
scene, the shared Time system, a timeline, a browsable API reference and
bounded NASA live comparisons. The README and wiki include screenshots of
these workflows.

The published GeoCalc crate is version 0.2.1. The private web package has its
own version, 0.1.1, and uses STKCraft Time 0.2.0; those are separate packages
and do not share a release counter.

It also includes representative native and WebGeocalc evidence and fixes for
point-target coincidence, limb angular size, event-search behavior and ray
field-of-view correction handling. The optional glibc rotation profile has a
bounded validation scope documented in the numerical contract.

NASA output-display equality does not prove equality to undisclosed internal
values or identical server kernel bytes. Complete WebGeocalc parity remains
unverified; see [the remaining gaps](../STRICT_REMAINING_GAPS.md).
