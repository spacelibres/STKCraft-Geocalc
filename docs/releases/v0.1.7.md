# STKCraft-Geocalc 0.1.7

This is an investigation checkpoint, not a published numerical release.
Publication remains blocked by thirteen remote exactness failures observed
in both Debug and Release on Windows Server 2022.

## Changes

- Record the failed remote acceptance run and the local native FMA dispatch
  experiment without editing numerical expectations.
- Add isolated C/Rust dynamic/static runtime diagnostics that record
  UCRT/native hashes, linker arguments, DLL imports, CPU support, default FMA
  state and raw binary64 results.
- Capture diagnostic artifacts on Windows Server 2022 and 2025 separately
  from the mandatory strict acceptance gate.

No production numerical algorithms have changed in this checkpoint. See
[the investigation](../reference/RUNTIME_MATH_INVESTIGATION.md) and
[remaining gaps](../STRICT_REMAINING_GAPS.md). Do not publish a version tag
until the numerical blocker is resolved and the complete CI passes.
